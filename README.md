# Kino.pub для Roku

Неофициальный клиент сервиса [kino.pub](https://kino.pub) для приставок и телевизоров Roku: каталог фильмов и сериалов, «Я смотрю», закладки, подборки, поиск (с русской клавиатурой), выбор озвучки и субтитров, фильтры, отметки просмотра и продолжение с места остановки. Интерфейс сделан в стиле Roku и рассчитан на управление обычным пультом. Нужна своя действующая подписка на kino.pub.

> Проект не связан с kino.pub и Roku. Канал ставится в режиме разработчика и в Roku Channel Store не публикуется.

## Установка на Roku

Понадобятся Roku в одной сети с компьютером и файл `kinopub.zip` (скачайте из раздела [Releases](../../releases) или соберите сами, см. ниже).

1. **Включите режим разработчика на Roku.** На пульте нажмите: `Домой ×3`, `Вверх ×2`, `Вправо`, `Влево`, `Вправо`, `Влево`, `Вправо`. Включите «Enable installer and restart», примите условия, задайте пароль и запомните IP-адрес Roku, который покажется на экране. Устройство перезагрузится.
2. **Загрузите канал.** Откройте в браузере `http://<IP Roku>`, войдите (логин `rokudev`, пароль из шага 1), в разделе Development Application Installer нажмите **Upload**, выберите `kinopub.zip` и **Install**. Либо из терминала:
   ```sh
   ./deploy.sh <IP Roku> <пароль>
   ```
3. **Войдите в аккаунт.** Канал запустится сам и покажет код. Введите его на странице активации устройства kino.pub (адрес покажет сам канал) под своим аккаунтом.
4. **Рекомендуется:** в канале откройте **Настройки → Рекомендуемые настройки**. Включатся HLS4, HEVC и 4K (если их поддерживает ваш Roku).

Канал появится в конце списка каналов на главном экране Roku; его можно перетащить выше (кнопка `*` на канале → Move channel).

## Возможности

- Вход по коду устройства (OAuth device flow), токены обновляются сами.
- Разделы: Главная, Я смотрю, Фильмы, Сериалы, 4K, Подборки, Закладки, Поиск, Настройки.
- Фильтры в каталоге: сортировка, жанр, страна, год (кнопка `*`).
- Рейтинги IMDb, Кинопоиск и Kino.pub на постерах и на странице, полное описание и состав в отдельном окне.
- Сериалы: сезоны и серии, продолжение с нужной серии и места, автопереход на следующую серию, отметка просмотра серии и целого сезона.
- Плеер: HLS/HEVC/4K, выбор озвучки (с автором перевода) и субтитров, диагностика потока.
- Отметка «Я смотрю» / «Буду смотреть» и трейлеры (где они есть на kino.pub).
- Поиск с экранной клавиатурой RU/EN/цифры и вводом с телефона через приложение Roku (подходит и для голосового диктования на телефоне).
- Кэш списков и индикатор состояния сервера слева внизу.
- Настройки устройства kino.pub прямо с телевизора: тип потока, сервер, 4K, HEVC, HDR, SSL.

## Управление

| Где | Кнопка | Действие |
|---|---|---|
| Меню слева | `Вправо` / `OK` | открыть раздел |
| Каталог | `*` | фильтры и сортировка |
| Карточка | `Вверх` с кнопок | выделить описание, `OK` — прочитать целиком |
| Карточка | `Вправо` от «Смотреть» | отметка «Я смотрю», затем трейлер |
| Список сезонов / серий | `*` | отметить сезон / серию просмотренными |
| Плеер | `Вниз` | озвучка и субтитры |
| Плеер | `Вверх` | показать / скрыть диагностику потока |
| Плеер | `Назад` | выход (позиция сохраняется) |

## Известные ограничения

- Roku не позволяет менять скорость воспроизведения в штатном плеере, поэтому такой функции нет.
- Пропуск заставок: у kino.pub в API нет таймкодов начала и конца заставки, автоматически пропускать её нечем (см. [ROADMAP](ROADMAP.md)).
- Русский голосовой ввод внутри канала невозможен (у приложений нет доступа к микрофону Roku), используйте диктовку на телефоне через приложение Roku.
- Кнопки Disney+ и подобные на пульте переназначить нельзя.

## Сборка и разработка

```sh
npm i -g brighterscript        # линтер/компилятор BrightScript
bsc --project bsconfig.json    # проверка кода
zip -r kinopub.zip manifest source components images
```

- Исходники: `source/` (точка входа), `components/` (SceneGraph-компоненты), `images/`.
- Данные приложения для API лежат в `components/lib.brs` (`kpConfig`): это публичные идентификаторы клиента, их можно заменить своими, выданными поддержкой kino.pub.
- Отладка: консоль Roku по `telnet <IP> 8085`. Строки `KP ...` в ней показывают запросы к API (токен скрыт).
- Подробнее: [docs/DEV.md](docs/DEV.md). История изменений: [CHANGELOG.md](CHANGELOG.md).
